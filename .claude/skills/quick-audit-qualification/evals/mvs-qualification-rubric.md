# MVS Qualification Rubric

## Criteria

| Criterion | Hard pass | Soft fail | Hard fail |
|---|---|---|---|
| LSA-eligible vertical | Eligible | None | Not eligible |
| Home service vertical | Listed home-service category | None | Non-home-service |
| Annual revenue | $2M+ | $1.5M-$2M | Below $1.5M |
| Reviews + rating | >=200 reviews and >=4.5 | 150-199 at >=4.5, or >=200 at 4.3-4.5 | Below soft band |
| GBP claimed | Claimed/verified | None | Not claimed/not found |
| Established | >=2 years | None | <2 years |

## Aggregation

- Any hard fail -> HARD-FAIL.
- Any soft fail and no hard fail -> SOFT-FAIL.
- All hard pass -> HARD-PASS.

## Independence

Qualification is independent of Quick Audit pillar grades.
