# Grading Approach Guide

Use anchored reasoning, not deduction arithmetic.

1. Enumerate signals first.
2. Compare against calibration anchors.
3. Assign grade by judgment within verbal bands.
4. Write rationale.
5. Preserve the rationale in Grading Notes.

See `references/source-docs/quick-audit-grading-approach-v1.md` for the full source document.
