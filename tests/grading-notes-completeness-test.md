# Grading Notes Completeness Test

## Purpose

Ensure every audit produces complete internal reasoning.

## Preconditions

- Claude Routine exists or local Claude Code session is available.
- Repository files are present.
- Required credentials are configured for the test.

## Steps

1. Open Grading Notes.
2. Confirm six pillar sections.
3. Confirm each has signals, anchor, grade, and rationale.
4. Confirm hard caps and data unavailable sections exist even if empty.

## Pass criteria

- All six pillars have complete grading evidence.
- Overall average is present.
- Hard caps and data unavailable are documented.

## Fail criteria

- Any pillar lacks signal list.
- Any grade lacks rationale.
- Overall grade math is missing or incorrect.
